Welcome to ULTIMATE-FILE-CONVERTER

This installer places the app in your Applications folder and sets up everything it needs to actually convert files.

The post-install step uses Homebrew to install:

  • FFmpeg — audio, video, and most image formats
  • ImageMagick — exotic image formats (AVIF, HEIC, SVG, ICO, …)
  • Pandoc — document formats (Markdown, HTML, DOCX, EPUB, LaTeX, …)
  • LibreOffice — Office documents (.docx / .xlsx / .pptx) and PDF export
  • Ghostscript, p7zip, librsvg — supporting tools

If Homebrew isn’t already installed, it will be set up automatically.

The first install can take 10–20 minutes (LibreOffice alone is ~600 MB). Progress is logged to /tmp/ufc-install.log if you want to follow along in Terminal with tail -f /tmp/ufc-install.log.
